# Guía de instalación

## Requisitos previos

Para instalar el proyecto CloudShop se necesita tener acceso al repositorio en GitHub, contar con Git instalado en el equipo y disponer de un editor de código como Visual Studio Code.

## Pasos de instalación

1. Clonar el repositorio desde GitHub.
2. Ingresar a la carpeta del proyecto.
3. Revisar los archivos de documentación disponibles.
4. Confirmar que la rama main contiene la versión actualizada del proyecto.

## Validación

Para validar la instalación, se debe verificar que el repositorio se haya clonado correctamente y que los archivos README.md y guia-instalacion.md estén disponibles en el entorno local.
